Looking for the original?

This page embeds Globe Crowd, an independent Farflung-inspired edition hosted on noillirk.co. For the original experience, visit Farflung. No scores or accounts are shared with that service.

If the game does not appear

Try reloading or opening it in a new tab. Browser privacy settings, network availability and the game service can affect embeds. The hub cannot confirm a completed game from an iframe load event. On phones, the independent page gives the game more room.

What is Farflung?

Farflung is associated with geography clues and choosing countries on a world map. The edition embedded here is Globe Crowd: it uses its own question bank and offers Popular and Rare modes. It is not the original Farflung daily puzzle.

A useful way to approach each question

Read the condition before choosing a familiar country. Check whether it refers to a border, capital, language or location. Select a country first, then confirm; the map selection alone does not submit your answer.

Farflung questions, answered

How many clues are in this edition?

A Globe Crowd flight contains five clues. Its question bank and estimated rankings are independent from original Farflung.

Does a rare country always score more?

That depends on the selected mode. Rare favors less obvious accepted answers; Popular favors the more common side of the edition’s editorial ranks. Neither is a live survey.

Is this today’s original Farflung?

No. This page opens an independent version. Use the original-game link below for the separate Farflung service.
