Know your score.

The development edition uses 21 test questions and simulated weights. Seven timed questions use fixed score bands; these are not real crowd percentages. The public API reports a test-only Cloudflare preview with multiplayer and authentication disabled. Full-round play has not been browser-verified.

Looking for the original?

This page embeds Popular Answers, an independent Noillirk-inspired edition hosted on noillirk.co. For the original experience, visit Noillirk. No scores or accounts are shared with that service.

If the game does not appear

Try reloading or opening it in a new tab. Browser privacy settings, network availability and the game service can affect embeds. The hub cannot confirm a completed game from an iframe load event. On phones, the independent page gives the game more room.

What is Noillirk?

Noillirk is a common-answer game: the challenge is to think of the answer other people are likely to give. It reverses the rare-answer goal associated with Krillion. This page embeds the independent Popular Answers preview, with a balloon-climbing theme and simulated weights.

A useful way to approach each question

Start with a direct answer that clearly fits the category. An obscure answer is not necessarily helpful in a common-answer game. If the preview does not recognize an answer, check its spelling or try another valid answer before the timer ends.

Noillirk questions, answered

How is Noillirk different from Krillion?

Noillirk aims toward familiar answers, while Krillion-style play aims toward less obvious valid answers. This hub’s two embedded editions also have separate question banks and scoring.

Are the answer percentages real player statistics?

No. This preview uses simulated weights and a small development question bank, not verified crowd survey results.

Can I play without a hub account?

Yes. Hub registration is not required. The game runs through a test-only public API; multiplayer and authentication are currently disabled.
